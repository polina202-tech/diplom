HTML теги: расшифровка аббревиатур

От каких английских слов произошли названия HTML-тегов

Основные структурные теги

<html> HTML
HyperText Markup Language — язык гипертекстовой разметки
Корневой элемент HTML-документа
<head> HEAD
Head — голова
Секция с мета-информацией о документе
<body> BODY
Body — тело
Содержит всё содержимое веб-страницы
<div> DIV
Division — раздел, отдел
Универсальный контейнер для группировки элементов
<span> SPAN
Span — охват, промежуток
Универсальный контейнер для строчных элементов

Теги заголовков и текста

<h1>-<h6> H
Heading — заголовок
Теги заголовков разных уровней (1-6)
<p> P
Paragraph — параграф, абзац
Определяет текстовый абзац
<a> A
Anchor — якорь, привязка
Создает гиперссылки (якорные ссылки)
<strong> STRONG
Strong — сильный, важный
Выделяет важный текст (полужирный)
<em> EM
Emphasis — ударение, акцент
Выделяет текст курсивом с семантическим акцентом

Списки и таблицы

<ul> UL
Unordered List — неупорядоченный список
Маркированный список
<ol> OL
Ordered List — упорядоченный список
Нумерованный список
<li> LI
List Item — элемент списка
Элемент списка (для ul и ol)
<table> TABLE
Table — таблица
Создает таблицу
<tr> TR
Table Row — строка таблицы
Создает строку в таблице

Мультимедиа и формы

<img> IMG
Image — изображение
Вставляет изображение на страницу
<video> VIDEO
Video — видео
Вставляет видео на страницу
<audio> AUDIO
Audio — аудио
Вставляет аудио на страницу
<form> FORM
Form — форма
Создает форму для ввода данных
<input> INPUT
Input — ввод, вводимые данные
Поле ввода данных в форме

Мета-теги и скрипты

<meta> META
Metadata — метаданные
Предоставляет метаданные о HTML-документе
<link> LINK
Link — связь, ссылка
Подключает внешние ресурсы (CSS, иконки)
<script> SCRIPT
Script — сценарий, скрипт
Подключает или содержит JavaScript-код
<style> STYLE
Style — стиль
Содержит CSS-стили для документа

Интересный факт: Многие HTML-теги являются аббревиатурами английских слов, что помогает запомнить их назначение. Например, зная, что "DIV" означает "division" (раздел), легче понять, что этот тег используется для разделения контента на логические блоки.
